# DragonForce - Console Game Store (C++)

This console-based application simulates a digital video game store similar to Steam.
Users can browse available games, view detailed descriptions, add games to their library,
and manage purchases. The application features a user-friendly interface, game
categorization, player profile management, and the ability for admins to edit games and users.

Designed to practice object-oriented programming, file handling, and user interaction
in a console environment.

**Context:** final project of the C++ course, IT STEP, 2023
**Technologies:** C++, OOP, file I/O, Visual Studio

## How to run
Open `C++ project.sln` in Visual Studio and run the project (Ctrl+F5).
